# Aura Drop - Privacy Policy

This repository hosts the official Privacy Policy webpage for the **Aura Drop** mobile application (`com.auradrop`), published via **GitHub Pages**.

## Live Webpage
Once GitHub Pages is enabled, this policy is served at:
`https://<your-username>.github.io/<repository-name>/`

## How to Enable GitHub Pages
1. Push this repository to GitHub.
2. Go to **Settings** > **Pages** in your GitHub repository.
3. Under **Branch**, select `main` (or `master`) and folder `/ (root)`.
4. Click **Save**.
5. Within 1–2 minutes, your Privacy Policy will be live and ready to link in Google Play Console and Apple App Store Connect.
